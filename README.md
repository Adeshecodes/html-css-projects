## How to view the exercises

1. Click **Code → Download ZIP** on this repository.
2. Extract the downloaded ZIP.
3. Open the `Project1` folder.
4. Double-click an HTML file, such as `buttons.html`, to open it in your browser.
5. To inspect or edit the code, open the extracted folder in VS Code.

Keep the files together so relative stylesheet links can work.
